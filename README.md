# 电信客户流失预测
Telco Customer Churn Prediction
## 📖 项目介绍
基于IBM电信公开数据集，通过探索性数据分析 + 机器学习，识别高流失风险客户，挖掘客户流失关键因素，输出业务挽留策略。
对比**逻辑回归、随机森林**两种分类模型，选出兼顾效果与业务可解释性的模型。

## 📊 数据集
- 数据集：IBM Telco‑Customer‑Churn
- 样本量：7043条，21个特征
- 目标标签：`Churn` 是否客户流失
- 问题类型：二分类，样本不平衡，整体流失率26.6%

## ⚙️ 技术栈
Python、Pandas、NumPy、Matplotlib、Seaborn
Scikit‑learn：Pipeline、ColumnTransformer、OneHotEncoder
模型：LogisticRegression、RandomForestClassifier

## 🧾 项目流程
1. **数据清洗**
处理TotalCharges字段空格缺失值，删除无效customerID，标签映射0/1，去重。
2. **EDA探索性分析**
统计流失分布，分析合约类型、支付方式、宽带业务、在网时长与流失关系，绘制热力图、统计图表，提炼高危流失用户画像。
3. **特征工程**
区分类别/数值特征，Pipeline流水线封装预处理，分层抽样划分训练集、测试集，避免数据泄露。
4. **模型训练与评估**
训练逻辑回归、随机森林；评估指标：准确率、精确率、召回率、F1、AUC、ROC曲线。
5. **特征重要性分析 & 业务结论**

## 📈 模型结果
| 模型 | AUC | 召回率 |
|------|-----|--------|
| 逻辑回归 | 0.836 | 0.572 |
| 随机森林 | 0.814 | 0.492 |

> 结论：**逻辑回归综合效果与可解释性更优，适合业务落地**。
> 关键影响因子：合约类型、在网时长、支付方式、月消费。

## 💡 业务发现
- 按月合约客户流失率远高于1/2年长期合约；
- 使用电子支票支付的客户流失风险更高；
- 未开通在线安全、技术支持增值服务的用户更容易流失；
- 在网时间越短，流失概率越高，新客户属于高危群体。
